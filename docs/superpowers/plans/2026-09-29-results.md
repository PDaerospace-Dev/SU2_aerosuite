# Results Page Implementation Plan

**Goal:** the Results page of `docs/superpowers/specs/2026-09-29-results-design.md`: chosen history parameters,
derived and characteristic values, packages, own plots with several Y, overlays of other designs, folding sections.

**Constraints:** test first; one commit per task; the full suite stays green. Tests: `uv run pytest -q -p no:cacheprovider`
(baseline 760 passed, 1 skipped). No `eval`. Studies without CL/CD work everywhere. The uncommitted prototype
(`web/pages/results.py` and small edits to `app.py`, `layout.py`, `status.py`, `theme.py`) is replaced in Task 5.

## Tasks

1. **Formula reader** — `engine/formula.py`: `parse(text) -> Formula` (names used, functions used), `evaluate(formula,
   values) -> float | Missing(reason)`, braces names, `^`, degrees; curve functions `slope/at/max/min/argmax/argmin`
   evaluated on a curve (`evaluate_curve`). Tests: `tests/engine/test_formula.py` (spec §7.1, §7.3 maths).
2. **Results settings, schema 6** — `models.ResultsSettings` (+ `DerivedValue`, `PlotSpec`), `Project.results`,
   `_v5_to_v6`. Tests: `test_project.py`/`test_results_settings.py` (§7.6).
3. **History parameters and convergence** — `results.history_columns` (union, counters out), `group_of`,
   `ordered_groups`; `summarize(..., convergence_columns=…)` with the "not judged" state; `study_constants` (S_ref,
   L_ref, ISA per case). Tests: `test_results.py` (§7.4, §7.5, §7.2 constants).
4. **Study results, characteristic values, packages** — `engine/study_results.py`: `study_results(folder, settings,
   definitions)` (summary + derived + characteristic values, overlays with the current study's definitions, notes for
   missing columns, cache by history size/mtime); `engine/packages.py` + `resources/packages/aero.json` (load, save,
   user override, availability, enable/disable bookkeeping). Tests: `test_study_results.py`, `test_packages.py`
   (§7.2, §7.3, §7.7, §7.8).
5. **Page skeleton** — replace the prototype: designs and filters card, Parameters card, the picker panel, tiles, the
   Results section, folding saved per study, the sidebar step enabled. Tests: `tests/web/test_web_results.py` (picker
   search, choose/remove, table, folding).
6. **Plots** — packages' plots, own plots, Add plot dialog (X, several Y, line rule shown and changeable), hollow
   unconverged points, PNG button, click → Monitor (`?case=`). Tests: web + a unit test of the line rule (§7.9).
7. **Derived dialog, characteristic values section, Save as package** — preview and errors, the section, the
   package dialog. Tests: web.
8. **Exports and CLI** — Copy table (TSV), Export CSV (+ `characteristics.csv`), `aerosuite summarize` using the saved
   settings. Tests: CLI + web (§7.10). README and HANDOVER.
